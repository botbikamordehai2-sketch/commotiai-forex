# WordPress Studio Agentic Beta — מסמך לימוד 01

## סטטוס מסמך
- מקור: WordPress.com Blog
- תאריך פרסום: 24 באוגוסט 2026
- מחבר: Jonathan Bossenger
- זמן קריאה מקור: 5 דקות
- סטטוס מוצר: Beta
- סביבת עבודה: Windows, macOS, Linux
- רמת סיכון: נמוכה באתר חי, כל עוד נשארים ב-Local
- כלל עבודה: Local → Review → Approval → Production

## מטרת המאמר
WordPress Studio קיבל ממשק Desktop חדש המבוסס על Agentic Development.

במקום לעבוד בנפרד עם:
- עורך קוד
- דפדפן
- חלון Admin
- כלי פיתוח מקומי
- צ'אט AI

הכלי מאחד את העבודה לחלון אחד:
- רשימת אתרים מקומיים
- סוכן AI בשם Studio Code
- תצוגה חיה של האתר

## מהו WordPress Studio
WordPress Studio היא סביבת פיתוח מקומית בקוד פתוח עבור WordPress.

היא מאפשרת:
- יצירת אתר WordPress מקומי חדש
- הפעלת אתרי ניסוי
- עבודה על Theme או Plugin
- גישה ל-WordPress Admin
- גישה לבסיס הנתונים המקומי
- Debugging
- Preview חי
- העברה ל-Staging או Production כאשר בוחרים בכך

האתר שנוצר אינו אתר "צעצוע".
זהו אתר WordPress מלא, נייד, שאפשר לתחזק ולהעביר לכל ספק אחסון מתאים.

## מה חדש ב-Agentic UI
הממשק החדש מחולק לשלושה אזורים:

### 1. Your Sites — צד שמאל
מטרתו לנהל את האתרים המקומיים.

פעולות אפשריות:
- לראות את כל האתרים
- ליצור אתר חדש באמצעות +
- לפתוח אתר קיים
- להתחיל או לעצור אתר
- לפתוח הגדרות אתר
- לעבור בין פרויקטים

לעובד קיים:
- אתרים מקומיים מהגרסה הישנה עוברים אוטומטית
- אין צורך לבצע Migration
- אין צורך ב-import
- אין צורך לבנות מחדש

### 2. Studio Code — מרכז
זהו סוכן AI המתמחה ב-WordPress.

הוא מכיר:
- WordPress Blocks
- Themes
- Plugins
- WP-CLI
- Scaffolding
- פקודות פיתוח
- התקנת WordPress מקומית

אפשר לתת לו הוראות בשפה רגילה.

דוגמה:
"בנה תבנית WordPress מהירה לבלוג מחקר Forex,
עם עמוד בית, כרטיסי מאמרים, אזור סיכום יומי,
דיסקליימר פיננסי, עמוד מקורות ועיצוב רספונסיבי."

הוא מיועד להאיץ עבודה חוזרת וטכנית,
אך לא להחליף החלטות מקצועיות או שיקול דעת של מפתח.

### 3. Live Preview — צד ימין
זהו האתר המקומי כפי שמבקר רואה אותו.

אפשר:
- לראות שינוי בזמן אמת
- ללחוץ על קישורים ולנווט באתר
- לבדוק Posts ו-Pages
- לפתוח את WordPress Admin
- לנהל מוצרים אם WooCommerce מותקן
- להציג Desktop, Tablet ו-Mobile
- לעבור ל-Full Screen
- לבדוק שכל שינוי אכן הופיע

## Annotate — מערכת ביקורת ותיקונים
כפתור Annotate מאפשר לסמן רכיב ישירות מתוך ה-Preview.

תהליך:

דוגמה לפרויקט Forex:

- סמן אזור נתונים
- כתוב: "הוסף זמן עדכון, מקור נתונים ודגל Freshness"

- כתוב: "פצל לתרחיש א' רגיעה ולתרחיש ב' התנגשות"

## זיכרון ושיחות
Studio Code שומר היסטוריית צ'אט,
כך שאפשר לעצור ולחזור לפרויקט בהמשך.

עם זאת, לפי תגובה של משתמשים והדיון באתר:
- שיחה חדשה היא נקודת התחלה חדשה
- אין להניח שכל ההקשר יעבור אוטומטית לשיחה חדשה
- יש לשמור תיעוד חיצוני של החלטות, Prompts וקבצים ששונו

לכן Notion או קובץ README הם מקור האמת שלך,
ולא זיכרון השיחה של כלי ה-AI.

לפני שינוי, הצג תוכנית קצרה ורשימת קבצים שצפויים להשתנות.
עבוד בשינויים קטנים ומופרדים.
אל תשמור API keys או סיסמאות בקוד.
אל תחליף קבצים שלמים כאשר אפשר לבצע שינוי ממוקד.
אחרי כל שינוי, תאר מה שונה, איך בודקים ואיך מבטלים.
שמור על תאימות WordPress סטנדרטית, ביצועים, נגישות ו-SEO."

## עבודה מקומית ובטיחות
כל העבודה ב-Studio מתבצעת מקומית.

המשמעות:
- אפשר לבדוק רעיונות ללא השפעה על האתר החי
- אפשר לשבור ולבנות מחדש ללא סיכון ל-Production
- אין פרסום אוטומטי
- אין העלאה לאתר חי בלי החלטה שלך
- ניתן לבצע Preview לפני כל שלב הפצה

העברה לסביבת אירוח נעשית כאשר מחליטים להשתמש ב-Studio Sync,
באמצעות תוכנית בתשלום של WordPress.com או Pressable.

## מה לא לעשות
- לא לחבר אתר חי לפני שנוצר אתר Local תקין
- לא לתת לסוכן Deploy אוטומטי
- לא לאשר שינוי גדול בלי להבין אילו קבצים השתנו
- לא לשמור מפתחות API בתוך Prompt, Theme או Plugin
- לא להחליף Theme פעיל באתר חי ישירות
- לא להסתמך על AI detector כהוכחה מהימנה למקור התוכן
- לא להניח ששיחה חדשה מכירה את ההיסטוריה הקודמת

## שימוש ב-AI ותוכן
WordPress.com מציינת שהשימוש בפיצ'ר אינו מוסיף סימון גלוי לקוראי האתר
שהתוכן נוצר בעזרת AI.

עם זאת:
- כלי גילוי AI חיצוניים אינם בשליטת WordPress.com
- תוצאותיהם אינן ראיה מהימנה
- כאשר שקיפות חשובה לקהל, אפשר להוסיף גילוי נאות עצמאי

מדיניות מומלצת לבלוג שלך:
- AI מסייע במחקר, מבנה, קוד וטיוטות
- אתה מאמת מקורות, נתונים ומסקנות
- אתה מקבל את החלטת הפרסום
- תוכן פיננסי לא מתפרסם ללא בדיקה אנושית

## מה חשוב להבין

Studio הוא **סביבת פיתוח מקומית עם סוכן AI**, לא מערכת שמחליפה את הבעלות שלך על האתר. האתר שנבנה הוא WordPress מלא ונייד, ואפשר לבחור לאחר מכן היכן לארח אותו. [wordpress](https://wordpress.com/blog/)

היתרון החשוב עבורך הוא לולאת עבודה מהירה: דרישה מתועדת → שינוי מקומי → Preview חי → Annotate ממוקד → בדיקה → אישור. זה מתאים ישירות למודל ה־sandbox וה־human-in-the-loop שאתה רוצה לשמור בפרויקטים שלך. [wordpress](https://wordpress.com/blog/)
